# Local development

## Option A – Docker (recommended)

```bash
cp .env.example .env        # set POSTGRES_PASSWORD
make up                     # docker compose up --build -d
make seed                   # load verified seed data
make logs
```

| Service | URL | Notes |
| --- | --- | --- |
| frontend | http://localhost:3000 | `next dev`; `frontend/src` is bind-mounted for hot reload |
| backend | http://localhost:8087/api/docs | `uvicorn --reload`; runs `alembic upgrade head` on start |
| db | internal only | Data in the `pgdata` volume; `docker compose exec db psql -U kmc khmer_moon_calendar` |

Both published ports bind to `127.0.0.1` only.

## Option B – Without Docker

Requires Python 3.13+, Node 22+ and Bash.

```bash
make setup     # creates backend/.venv, installs npm packages, migrates and seeds
make dev       # backend :8087 + frontend :3000
```

Without `DATABASE_URL`, the backend uses `backend/khmer_moon_calendar.db` (SQLite). For PostgreSQL, run:

```bash
export DATABASE_URL=postgresql+psycopg://user:password@localhost:5432/khmer_moon_calendar
```

## Database initialization and migrations

1. On first start of a fresh volume, PostgreSQL runs `infra/database/init/*.sh`, which sets the database timezone.
2. `alembic upgrade head` creates or updates the schema (run automatically by the dev backend container).
3. `python -m app.db.seed` loads `infra/database/seeds/verified/*.json`. It is idempotent and upserts by slug or name.

Create a migration after changing models:

```bash
cd backend && alembic revision --autogenerate -m "add x" && alembic upgrade head
```

Review the autogenerated file before committing.

## Testing

```bash
make test                               # backend pytest + frontend vitest
TEST_DATABASE_URL=postgresql+psycopg://… make test   # backend tests against PostgreSQL
make test-e2e                           # Playwright; needs the stack running on :3000
E2E_BASE_URL=http://localhost npx playwright test     # against the production compose
```

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| `POSTGRES_PASSWORD` error on `docker compose up` | Create `.env` from `.env.example` |
| Frontend shows "Today's date could not be loaded" | Backend not reachable. Check `API_INTERNAL_URL` and `curl localhost:8087/api/v1/health` |
| `/` opens `/km` even though the browser is English | Intended: Khmer is the default. Use the language switcher. |
| Windows: `DLL load failed … Application Control policy` when importing SQLAlchemy | A device policy blocks compiled extensions. Reinstall the pure-Python build: `DISABLE_SQLALCHEMY_CEXT=1 pip install --force-reinstall --no-binary sqlalchemy SQLAlchemy==2.1.6` |
| Scripts fail on Windows | Run them from Git Bash, or use `docker compose` directly |
| Port 3000 or 8087 in use | Stop the other process, or change the published port in `docker-compose.yml` |
